Please read before using the assessment tool.

LoanML is a coursework project built for the Common Project Model (Phase 1) under the Computer Engineering Department's ML Project SOP. It estimates the probability that a loan applicant will default, based on a logistic regression model trained on a historical, publicly available dataset of 255,347 loan records.

This is not a lending decision. The model was built for learning and research purposes. It has not been validated for regulatory, compliance, or production lending use, and its accuracy (88.5%) reflects performance on historical test data, not a guarantee for any individual application.

No personal data submitted through this form is stored, logged, or shared. Figures entered here are used only to compute the estimate displayed on the result page.

For an actual credit decision, consult a licensed loan officer or financial institution.
